Week 2: Making my first website

Week 02 / 8 October 2026

Making my first website

This was my first time making a webpage. In the workshop, we tried CampusPress and learned some basic HTML and CSS. I chose GitHub Pages because I want to try changing the design myself.

After class, I read the instructions carefully and practised using HTML and CSS. CampusPress has themes that are already available, while HTML and CSS let us change more things. This helped me see how different tools affect what we can make.

This is my first version. I would like to try different designs and add more of my work as I learn.
